# 星际保卫者 · 离线静态版

本仓库为可直接托管的 HTML / JavaScript / Cocos 游戏，所有运行素材使用站内相对路径，无需 Python 服务或原网站登录。

## 运行与存档

GitHub Pages 从 main 分支根目录发布。也可用任意静态 HTTP 服务启动本目录。

Cloudflare 正式站点：https://sc2.tkfm.club/ 。每次推送 main 后，GitHub Actions 自动测试、生成带内容版本的发布目录并部署 Cloudflare Pages。当前部署提交见 `/release.json`，失败的测试不会覆盖线上版本。

本地验证：`node --test tests/*.test.cjs`；生成发布目录：`node scripts/prepare-site.cjs`。发布只使用 GitHub 工作流生成的 dist，不再从其他本地游戏目录手动覆盖。资源包需要 HTTPS 或 localhost。

进度保存在浏览器当前网站的本地存储中，不同域名之间不会自动共享；迁移请先在原站导出存档，再在新站导入。

## 基地攻击修正

普通基地保留原关卡攻击。仅对关卡基地弹丸细分移动碰撞检测，避免4倍速低帧率下子弹跳过目标；竞技场基地仍不攻击。

## 建筑出售

战斗中、开战前及波次间建造阶段，点击己方兵营、重工、机场或炮塔均可出售，返还 100 晶矿；基地与行星要塞不可出售。建造按钮与建筑重叠时优先响应建筑，关闭出售窗口后可继续建造或开战。出售立即停止该建筑生产，保留已生产部队及已购升级，不返还升级费用。同类建筑的重建选项本局归入最低补位组，与建筑血量、攻击和整体生产速度选项同组；续玩保留该记录。

本地逻辑验证：`node --test tests/building-sale.test.cjs`。浏览器集成验证页：`tests/building-sale.html`（请使用独立的本地测试地址，以隔离正式存档）。
